# Sales Pouch Pro

Build a mobile-first web application "Sales Pouch" for field sales (consignment & direct sales) using React, Tailwind, and Supabase.

### 1. Database & Core Tables
- `profiles`: business_name, user_email, created_at.
- `outlets`: id, name, map_location, owner_phone, store_photo, created_at.
- `transactions`: id, receipt_number (SP-YYYYMMDD-XXX), outlet_id, sales_name, visit_date, transaction_type ('Consignment'|'Direct Sale'), line_items (JSON), total_sales, previous_debt, total_due, amount_paid, remaining_debt, new_consignment_items (JSON), custom_note.

### 2. Access Control
- License/Trial: 
  - Bypass if user email is "ganlapor@gmail.com".
  - 24-hour free trial based on profile `created_at`.
  - If expired & no license, show block page with text: "Masa trial 24 jam Anda telah berakhir. Silakan hubungi admin untuk memperpanjang lisensi." and Telegram button link: "https://t.me/yayazimu".

### 3. Workflow & Forms
- **First-Time Setup**: Set Business/Distributor Name.
- **Outlet Management**: Add outlet (name, GPS/map link, phone, photo upload).
- **Smart Visit Flow**:
  - Select outlet -> Input Sales Name.
  - FIRST visit (no history): Skip calculation, open clean "New Consignment Drop-off" form (Total = Rp 0).
  - ROUTINE visit (has history): Auto-pull previous consignment stock.
- **Consignment Calculation**: 
  - Per product: Sold qty x unit price = subtotal, Return qty, Remaining stock (auto).
  - Financials: Previous debt + total sales = total due -> input amount paid -> remaining debt.
  - Optional `custom_note` field.

### 4. Thermal Receipt Generator
- Generate digital thermal-style receipt after submission.
- **Header**: Business Name, No Nota (`receipt_number`), Store, Sales, Visit Date.
- **Line Items**: Product Name, Titip Sebelumnya, Terjual x Harga = Subtotal, Retur.
- **Debt Logic**: If `previous_debt > 0`, show full financial breakdown. If `previous_debt = 0`, hide debt lines and show: "TOTAL TAGIHAN / DIBAYAR : Rp [X] (Status: Lunas / Tanpa Tunggakan) ✅".
- **New Consignment**: List new items dropped off today.
- **Custom Note**: Render in `text-xs text-gray-500` right above footer *only if not empty*.
- **Footer**: "Terima Kasih 🙏" & "*Generated by Sales Pouch*".

Mulai bangun Sales Pouch dengan menyiapkan skema Supabase dan alur setup bisnis serta outlet terlebih dahulu.
